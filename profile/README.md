## 🪖 프로젝트 소개

>병 봉급 인상과 장병내일준비적금 확대로 군 복무 기간은  
생애 첫 규칙적인 소득과 저축을 경험하는 중요한 시기가 되었습니다.
>
>하지만 기존 군인 금융 서비스는 자산 조회와 금융 정보 제공에 머무르는 경우가 많아,  
현재의 소비·저축·투자 선택이 전역 시점의 자산에 어떤 영향을 주는지 파악하기 어렵습니다.

**제대로**는 군 복무 정보와 계급별 미래 소득, 연동된 금융 데이터를 활용해  
현재부터 전역까지의 자산 흐름을 예측하는 **군 특화 AI 자산관리 서비스**입니다.

계급별 급여와 진급 일정, 장병내일준비적금의 이자와 정부지원금을 반영하고,  
What-if 시뮬레이션을 통해 소비·저축·투자 계획에 따른 전역 예상 자산과  
재정적 전역일의 변화를 보여줍니다.

또한 AI 금융 분석과 맞춤형 투자 추천, 미션과 챌린지를 통해  
사용자가 전역 이후에도 지속할 수 있는 올바른 금융 습관을 형성하도록 돕습니다.

## 💸 전역까지 계산하는 캐시플로우 엔진

제대로는 단순히 현재 잔액만 보여주지 않습니다.  
군 복무가 끝나는 시점까지 매월 발생할 현금흐름을 계산합니다.

```text
현재 자산
   +
계급별 월급과 진급 일정
   +
적금 원금·이자·정부 매칭지원금
   +
월 저축·투자 계획과 기대수익률
   -
월 소비 목표와 이벤트성 지출
   ↓
전역 예상 자산 · 목표 달성률 · 재정적 전역일
```

| 반영 항목 | 계산 기준 |
| --- | --- |
| 계급별 급여 | 군종·계급·봉급 정책 적용 기간 |
| 진급 일정 | 육군 `2/6/6/4`, 해군 `2/6/6/6`, 공군 `3/6/6/6` |
| 군 적금 | 연결 계좌 이율, 예상 원금, 정부지원금 |
| 미래 소비 | 사용자 소비 목표와 이벤트성 지출 |
| 미래 투자 | What-if 투자금과 기대수익률 |
| 재정적 전역일 | 목표 금액에 처음 도달하는 날짜 |

## 🔄 What-if 시뮬레이션

저축·투자·소비 계획을 변경하면 캐시플로우 엔진이  
전역일까지의 자산 흐름을 다시 계산합니다.

```text
월 저축액 변경

월 투자액 변경

월 소비액 변경

기대수익률 변경
        ↓
캐시플로우 재계산
        ↓
전역 예상 자산 · 목표 달성률 · 재정적 전역일 갱신
```

사용자가 적용한 시뮬레이션은 대시보드에도 반영되어  
현재 계획과 변경된 계획의 결과를 비교할 수 있습니다.

## 🤖 필요한 곳에만 AI를 사용합니다

### AI 거래 분류

모든 거래를 AI에 전송하지 않습니다.

```text
CODEF 거래내역
    ↓
RULE 기반 1차 분류
    ├─ 분류 가능 → 즉시 카테고리 저장
    └─ 판단이 어려운 출금 → AI 보완 분류
                              ↓
                        사용자 직접 수정
```

급여, 적금 이체, PX 결제와 구독료처럼 형식이 명확한 거래는 RULE로 처리하고,  
상호명만으로 판단하기 어려운 출금에만 AI를 제한적으로 사용합니다.

### ETF 추천

ETF 추천은 단순한 최근 수익률 순위가 아니라  
사용자의 투자성향과 실제 투자 가능성을 기준으로 합니다.

| 평가 기준 | 기본 배점 |
| --- | ---: |
| 자산배분 적합도 | 40점 |
| 투자성향 적합도 | 25점 |
| 유동성 | 15점 |
| NAV 괴리율 | 10점 |
| 시가총액 | 10점 |

월 투자 가능 금액, 전역까지 남은 기간, 기존 보유 상품과의 중복을 추가로 반영해  
군 복무 중에도 지속할 수 있는 상품을 추천합니다.

## 🌴 군 생활에 맞춘 자산관리

### 휴가 모드

휴가 기간을 설정하면 해당 기간의 거래내역을 별도로 집계하고,  
휴가 예산과 실제 지출을 비교할 수 있습니다.

### 장병 혜택

교통, 여가, 자기계발, 숙박, 기타 카테고리로  
군 장병이 이용할 수 있는 카드·휴가 혜택을 제공합니다.

### 미션과 챌린지

금융 습관을 미션으로 구성하고, 미션 완료와 뱃지 획득을 통해  
지속적인 자산관리를 유도합니다.
